# interface-localization

## Purpose

讓 CodeWalk 面板的介面文案(畫面標題、操作名稱、狀態提示等)跟隨 VS Code 編輯器的顯示語言呈現繁體中文或英文,同時保持導讀內容(`.codewalk.json` 中作者撰寫的文字)與格式驗證錯誤訊息不受介面語言影響——讓讀者不必在 CodeWalk 內另外設定語言,也不會混淆「播放器自身文案」與「導讀原文」的語言歸屬。

## Requirements

### Requirement: 介面語言跟隨編輯器顯示語言

系統 SHALL 依 VS Code 目前的顯示語言決定介面語言:顯示語言為中文(不論任何地區變體)時 SHALL 使用繁體中文,其餘一切語言 SHALL 使用英文。無法取得顯示語言時 SHALL 使用英文。

系統 SHALL NOT 提供獨立於編輯器顯示語言的語言設定項,讀者 SHALL NOT 需要在 CodeWalk 內另外選擇語言。

#### Scenario: 繁體中文編輯器

- **GIVEN** 讀者的 VS Code 顯示語言為繁體中文
- **WHEN** 讀者開啟 CodeWalk 面板
- **THEN** 面板上的畫面標題、操作名稱與狀態提示皆以繁體中文呈現

#### Scenario: 英文編輯器

- **GIVEN** 讀者的 VS Code 顯示語言為英文
- **WHEN** 讀者開啟 CodeWalk 面板
- **THEN** 面板上的畫面標題、操作名稱與狀態提示皆以英文呈現

#### Scenario: 簡體中文編輯器歸入中文

- **GIVEN** 讀者的 VS Code 顯示語言為簡體中文
- **WHEN** 讀者開啟 CodeWalk 面板
- **THEN** 面板以繁體中文呈現,不以英文呈現

#### Scenario: 系統未提供對應語言時降級為英文

- **GIVEN** 讀者的 VS Code 顯示語言為系統未提供翻譯的語言(例如日文、德文)
- **WHEN** 讀者開啟 CodeWalk 面板
- **THEN** 面板以英文呈現,不出現空白文字、未翻譯的識別字或錯誤訊息

#### Scenario: 無法取得顯示語言

- **GIVEN** 系統無法取得編輯器目前的顯示語言設定
- **WHEN** 讀者開啟 CodeWalk 面板
- **THEN** 面板以英文呈現,不中斷面板載入、不顯示錯誤訊息

### Requirement: 介面文案與導讀內容的邊界

系統 SHALL 讓面板上一切由播放器產生的文案隨介面語言呈現,包含畫面標題、操作名稱、步驟計數、狀態提示與各類警告。

導讀內容本身 SHALL 原樣呈現,SHALL NOT 因介面語言而被翻譯、改寫或隱藏。導讀內容指 `.codewalk.json` 中由導讀作者撰寫的一切文字:`title`、`step.title`、`narration`、`term` 的名詞與解釋、`items` 各項目的文字、quiz 的題目、選項與選項解釋、以及 `regenerateHint`。

#### Scenario: 英文介面播放繁體中文導讀

- **GIVEN** 讀者的介面語言為英文,載入一份以繁體中文撰寫的導讀
- **WHEN** 讀者瀏覽任一 step
- **THEN** 播放器自身的操作名稱與步驟計數以英文呈現,該 step 的標題與敘述維持繁體中文原文,兩者同時顯示於畫面上

#### Scenario: 繁體中文介面播放英文導讀

- **GIVEN** 讀者的介面語言為繁體中文,載入一份以英文撰寫的導讀
- **WHEN** 讀者瀏覽任一 step
- **THEN** 播放器自身的文案以繁體中文呈現,該 step 的內容維持英文原文,系統不對其做任何翻譯或標註

#### Scenario: quiz 內容不隨介面語言變動

- **GIVEN** 讀者的介面語言為英文,某份導讀的 quiz 題目與選項以繁體中文撰寫
- **WHEN** 讀者進入 quiz 作答並檢視結果
- **THEN** 題目、選項與選項解釋維持繁體中文原文,而分數呈現、過關與否的提示、重新挑戰與返回等操作名稱以英文呈現

### Requirement: 指令與擴充套件描述的雙語

系統 SHALL 讓指令面板中的 CodeWalk 指令名稱、以及擴充套件在擴充套件檢視與 Marketplace 頁面上的描述,隨編輯器顯示語言呈現對應語言。擴充套件的顯示名稱 SHALL 維持 `CodeWalk` 不隨語言變動。

#### Scenario: 英文編輯器的指令名稱

- **GIVEN** 讀者的 VS Code 顯示語言為英文
- **WHEN** 讀者開啟指令面板並搜尋 CodeWalk 的指令
- **THEN** 指令名稱以英文顯示

#### Scenario: 繁體中文編輯器的指令名稱

- **GIVEN** 讀者的 VS Code 顯示語言為繁體中文
- **WHEN** 讀者開啟指令面板並搜尋 CodeWalk 的指令
- **THEN** 指令名稱以繁體中文顯示

### Requirement: 格式驗證錯誤固定英文

系統產生的 `.codewalk.json` 格式驗證錯誤訊息 SHALL 一律為英文,SHALL NOT 隨介面語言變動。此為介面語言規則的明確例外:驗證錯誤是格式合約的診斷輸出,受眾是撰寫導讀或開發產生器的人,且經常被複製到 issue、log 等跨語言情境,固定語言比隨介面浮動更有用。

驗證錯誤訊息 SHALL 維持既有的資訊要求——指出違規欄位的路徑與不符的原因,使讀者能定位到 `.codewalk.json` 中的具體位置。

#### Scenario: 繁體中文介面下的格式錯誤

- **GIVEN** 讀者的介面語言為繁體中文,選擇一份 `startLine` 不是正整數的導讀
- **WHEN** 系統嘗試載入該檔案
- **THEN** 系統以英文顯示格式錯誤訊息並中止載入,訊息中指出違規欄位的路徑

#### Scenario: 英文介面下的格式錯誤

- **GIVEN** 讀者的介面語言為英文,選擇一份不符 schema 的導讀
- **WHEN** 系統嘗試載入該檔案
- **THEN** 系統以英文顯示格式錯誤訊息並中止載入,內容與繁體中文介面下顯示的完全相同

#### Scenario: 錯誤訊息以外的載入失敗提示仍隨介面語言

- **GIVEN** 讀者的介面語言為繁體中文,且目前沒有開啟任何 workspace
- **WHEN** 讀者開啟 CodeWalk 面板
- **THEN** 系統以繁體中文顯示「未開啟 workspace」這類播放器自身的狀態提示——固定英文的例外僅限格式驗證錯誤

### Requirement: 變更顯示語言後的行為

讀者變更 VS Code 顯示語言並依編輯器要求重新載入視窗後,系統 SHALL 以新語言呈現全部介面文案,SHALL NOT 要求讀者重新安裝擴充套件或清除任何設定才能套用。

留存資料 SHALL NOT 因介面語言變更而遺失或失效:各導讀的閱讀進度、作答紀錄與其接續入口 SHALL 在語言變更後維持原狀。

#### Scenario: 變更語言後介面隨之改變

- **GIVEN** 讀者原本以繁體中文介面使用 CodeWalk
- **WHEN** 讀者將 VS Code 顯示語言改為英文並重新載入視窗,再開啟 CodeWalk 面板
- **THEN** 面板上的畫面標題、操作名稱與狀態提示皆改以英文呈現

#### Scenario: 變更語言不影響留存的進度與紀錄

- **GIVEN** 某份導讀留有第 12 步的進度與一筆作答紀錄,讀者原本使用繁體中文介面
- **WHEN** 讀者將顯示語言改為英文並重新載入視窗,開啟導讀選擇畫面
- **THEN** 該導讀的接續入口仍顯示並標示第 12 步,作答紀錄的分數與時間仍顯示,兩者皆以英文呈現其文案
